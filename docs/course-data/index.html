Open course data

The open database used by GolfScoring contains 518 published course routings. Download the data and its location and routing corrections without an account.

  • Download course database · JSON
  • Download location and routing corrections · JSON
  • Source and licence notes
  • Original database licence notice

This adapted database is available under the Open Database License 1.0. Course data comes from yardage-hub, including OpenStreetMap data (© OpenStreetMap contributors), and from OpenStreetMap via OpenGolfAPI. Identity and locality fields may also include Foursquare Open Source Places and Overture Maps under Apache 2.0.

Each course record identifies its source. Distances are in yards. The corrections file accompanies the database and records corrected localities and repeated or reversed nine-hole routings. The snapshot was checked on November 14, 2026; actual tee markers can change.

These downloads cover the open database only. Other independently sourced course scorecards are outside this dataset. The database licence does not change the proprietary licence of the GolfScoring application.

开放球场数据库

GolfScoring 使用的开放数据库包含 518 条已发布球场线路。无需账号即可下载数据及其地点、线路修正。

  • 下载球场数据库（JSON）
  • 下载地点与线路修正（JSON）
  • 数据来源与许可说明
  • 原始数据库许可声明

本修订数据库按 ODbL 1.0 开放数据库许可证提供。数据来源为 yardage-hub（含 © OpenStreetMap 贡献者的数据）及通过 OpenGolfAPI 提供的 OpenStreetMap 数据。名称和地点字段还可能包含按 Apache 2.0 提供的 Foursquare Open Source Places 与 Overture Maps 数据。各球场记录附有对应来源，距离单位为码。

配套修正文件包含地点修正及重复、反向九洞线路说明。此版本数据核对日期为 2026 年 11 月 14 日，实际发球台标志可能变化。下载范围仅为开放数据库，不包含其他独立来源的球场记分卡；数据库许可不改变 GolfScoring 应用本身的专有许可。
