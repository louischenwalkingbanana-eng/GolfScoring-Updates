# GolfScoring desktop downloads and updates

GolfScoring is proprietary software. This repository distributes the official desktop installers and the signed update feed. The application source is private.

Download GolfScoring for Windows x64, macOS Intel, macOS Apple Silicon, or Linux x64 from [Releases](https://github.com/louischenwalkingbanana-eng/GolfScoring-Updates/releases). Install version 1.3.2 or later once to enable automatic updates. The app checks for new releases while you use it and asks before installing.

| Platform | Download |
| --- | --- |
| Windows x64 | The Windows installer ending in `.exe` |
| macOS with Apple Silicon | The disk image ending in `mac-arm64.dmg` |
| macOS with Intel | The disk image ending in `mac-x64.dmg` |
| Linux x64 | The file ending in `.AppImage` |

GolfScoring checks the publisher's signature on `stable.json` and verifies the size and SHA-256 checksum of the installer before applying an update. Scorecards stay on your device.
